## Our standard

Everyone who takes part in this project, in issues, discussions, pull requests and reviews, is treated with respect.
Be precise and kind. Critique code and claims, never people.
Harassment, personal attacks, discriminatory language and the publication of anyone's private information are not accepted.

[↑ Back to Contents](#contents)

## Scope

This code applies in every space of this project, and wherever a person represents the project in public.

[↑ Back to Contents](#contents)

## Reporting

Report conduct that breaks this code to the maintainer through a private security advisory on this repository, marked as a conduct report.
Every report is read, and the reporter's identity is kept private.

[↑ Back to Contents](#contents)

## Enforcement

The maintainer may edit or remove contributions, and may warn, suspend or ban a participant whose conduct breaks this code.
This code draws on the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org).
