# src/bin

## Contents

- [src/bin](#srcbin)

This folder holds three of the four role programs. Each file is a thin start line for one role.

**Belongs here:** One small file per role program that is not the full role.

**Does not belong here:** Role logic. Logic lives in the library and in `dispatch.rs`.

The full role starts at `src/main.rs`. This folder holds the deadline, gate, and contain roles.
