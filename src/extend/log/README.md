# src/extend/log

## Contents

- [src/extend/log](#srcextendlog)

This folder holds the two pure parts of the extension log. The parent file `src/extend/log.rs` holds the rest of the log module.

**Belongs here:** The audit record form and the log line form.

**Does not belong here:** Grant decisions. The serve folder holds the decision side.

`audit.rs` and `format.rs` are pure files. Each states one form and decides nothing.

**Next:** The [extend README](../README.md) states the extend layout.
