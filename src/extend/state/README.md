# src/extend/state

## Contents

- [src/extend/state](#srcextendstate)

This folder holds the process part of the extension run state. The parent file `src/extend/state.rs` holds the rest of the state module.

**Belongs here:** The record of one process inside one extendable run.

**Does not belong here:** Grant decisions and log forms. Each has its own home in the extend group.

**Next:** The [extend README](../README.md) states the extend layout.
