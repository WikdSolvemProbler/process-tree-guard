# src/extend/serve

## Contents

- [src/extend/serve](#srcextendserve)

This folder holds the decision part of the extension server. The parent file `src/extend/serve.rs` holds the rest of the serve module.

**Belongs here:** The one file that decides a hold request.

**Does not belong here:** Log forms and run state. Each has its own home in the extend group.
