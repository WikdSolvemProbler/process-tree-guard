# src/sys/windows

## Contents

- [src/sys/windows](#srcsyswindows)

This folder holds the parts of the Windows backend that stand as their own files. The backend module `src/sys/windows.rs` holds the declarations.

**Belongs here:** The random-number part of the Windows backend.

**Does not belong here:** Declarations for any other system. No other system has a backend at this version.

Windows is the proven backend at this version. Every declaration for Windows stands in the backend module or in this folder.
