## Contents

- [src/cli_process](#srccli_process)

This folder holds the parts of the child-process module that stand as their own files. The parent file `src/cli_process.rs` holds the rest of the module.

**Belongs here:** The hardening steps and the standard-stream handling for a child process.

**Does not belong here:** Process creation rules that the engine owns.
