Generated by `tools/gen_dependency_graph.py` from the tree at
`~/workspace/pgl-gauntlet/tree/`. Do not hand-edit: regenerate after
any file move. `tools/design-gate.sh` (D4) fails while the line
counts below are stale. Edges are mechanical: a `mod` declaration
(parent -> child) or a textual `crate::<module>` reference in the
file, where the name after `crate::` is one of the crate's declared
modules (references to root types, constants and functions are not
module edges and are not listed). Submodule files also glob-import their parent (`use super::*;`),
which is how they reach the parent's re-exports; that channel is
structural, not an edge per file. `sys` does not travel it:
every production file imports the sys names
it uses from `crate::sys` explicitly, in its own text, and the
Files table's census counts that coupling per file.
The crate root (`src/lib.rs`) can name its own modules bare, so for
that file alone a declared module named as a path head (`<module>::`)
also counts as an edge.

The Files table also carries, per production file, its direct-sys-call
census: the count of call sites of the functions declared in the
production `extern` blocks of `src/sys/windows.rs`, matched by name over the
file's production text, the file with its `#[cfg(test)]` items and
modules removed, the production definition the design gate's
production-line counter applies, so test code is not counted as
production coupling. A production file is a file under `src/`
excluding any `tests.rs` file, `tests/support/testkit.rs` (a separate
program, counted in its own right by design gate D44) and the `sys`
subtree itself, and excluding any file whose every `mod`
declaration in its parent chain is `#[cfg(test)]`-gated: the
production definition sees the parents' declarations, resolved to
their actual target files (a `#[path = "..."]` attribute on a
declaration, or on an enclosing inline module, is honoured, and
file-module children of an inline module resolve under that
module's directory, as a `src/bin/*.rs` root's children resolve
beside the root), so a file with any ungated declaration, by
whatever path, is production, and such a file as has none is test
code, recorded as such below, not production;
non-production rows show, in that column. A
production file whose census is non-zero shows its `sys` edge in the
cross-module table even when its own text names no `crate::sys`,
because its own header imports the names from `crate::sys`.
