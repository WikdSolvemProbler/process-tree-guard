## Sources

Each logo is the sponsor's own artwork, retrieved 04NOV2026. The light file is for a light page and the dark file for a dark page; the dark versions change only the colour of the wordmark lettering to white, as each sponsor does on its own dark pages. The logos are trademarks of their owners and are not covered by this project's licence.

|---|---|
| `meta-light.svg` | https://upload.wikimedia.org/wikipedia/commons/7/7b/Meta_Platforms_Inc._logo.svg |
| `meta-dark.svg` | The same file, wordmark lettering in white. |
| `modal-dark.svg` | https://modal.com/_app/immutable/assets/modal-logo-dark-background.CjFn2CQh.svg |
| `modal-light.svg` | The same file, wordmark lettering in black. |
| `fireworks-light.svg` | The "Fireworks AI" wordmark served inline on https://fireworks.ai, lettering in black. |
