# bins

## Contents

- [bins](#bins)

This folder holds the three preserved competitor programs, as found. The build reads the programs from here when no other staging source is named.

**Belongs here:** The three programs of the set, flat, with no other file.

**Does not belong here:** Built guard programs. The build stages guard programs in `build/`, not here.

Each program stands under the `SHA-256` pin that `campaign.json` states for it. A program whose checksum is not the pin is not the preserved competitor.
