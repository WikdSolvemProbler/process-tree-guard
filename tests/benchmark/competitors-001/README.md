# competitors-001

## Contents

- [competitors-001](#competitors-001)

This folder holds the preserved competitor set. Its run manifest records the competitor programs of the preserved campaign.

**Belongs here:** The run manifest and the folder of the competitor programs.

**Does not belong here:** New competitor programs. A new program enters only as a new preserved set, with its own manifest.

`run-manifest.json` records the name, the size, and the `SHA-256` checksum of each program in the set.

**Next:** The [bins folder](bins/README.md) holds the programs.
